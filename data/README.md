# 试卷数据

原始文件和结构化内容分开保存，再按考试类型和年月分目录：

```text
data/
├── sources/                      # 用户提供的原始 PDF
│   └── cet4/2026-06/
│       ├── 2026-06-CET4-1.pdf
│       └── 2026-06-CET4-2.pdf
└── papers/                       # 校对后的试卷 JSON，生成数据库数据的来源
    └── cet4/2026-06/
        ├── cet4-2026-06-1.json
        └── cet4-2026-06-2.json
```

考试目录使用 `cet4`、`cet6`、`neep`；年月目录使用 `YYYY-MM`。新增类型或年份时按同样结构创建子目录即可。

## 添加试卷

1. 把原始 PDF 放入 `sources/<考试>/<年月>/`。
2. 阅读并校对非听力内容，把对应 JSON 放入 `papers/<考试>/<年月>/`。PDF 本身不会自动转换为试题；跨页段落、双栏选项和题号需要核对。
3. JSON 包含试卷元数据、`sections`、原题 `paragraphs`、精读 `study_paragraphs` 和 `questions`。每道题保留题干、选项、答案来源说明和分值；写作、翻译未提供参考答案时使用 `answer: null`。
4. 运行 `npm run seed:generate`，再运行 `npm run check` 和 `npm run build`。
5. 提交推送后，自动部署将生成的 SQL 导入 PostgreSQL；上线验证会逐张核对题目、原文和精读句子。

生成器与上线验证会递归扫描 `papers` 下的 JSON，无需逐张修改脚本。原始 PDF 只用于核对，不作为前端或数据库直接读取的数据。

`id`、章节 ID、题目 ID 是稳定标识，移动文件时保持它们和原文不变，已有做题记录和精读缓存可以继续使用。重复的试卷、章节或题目 ID 会在生成 SQL 前报错。

当前两套 PDF 均没有答案页。客观题参考答案依据原文整理，并非官方答案；选词填空的精读文本按参考答案补全，做题模式保留原题空格。AI 生成的精读结果保存在数据库中，不写回试卷 JSON。
